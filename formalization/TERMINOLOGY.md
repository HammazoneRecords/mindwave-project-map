# Terminology

| Term | Meaning |
|---|---|
| Map | Versioned facts describing a project surface. |
| Node | An addressable thing in a Map. |
| Edge | A declared relationship between nodes. |
| Role | An actor or context used for traversal and permission checks. |
| Capability | An action that may be invoked. |
| Journey | A test or steering path through a Map. |
| Step | One movement, action, assertion, or checkpoint in a Journey. |
| Trace | Evidence emitted by a Journey run. |
| Finding | A diagnosed issue or mismatch derived from a Trace. |
| Skin | A visual, CLI, CI, or integration interface over the model. |
| Drift | A mismatch between the Map and the system it describes. |

## Core sentence

**the map is the facts. the journey is the test / steer.**
